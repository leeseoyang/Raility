## 2026H1 기간 정합 집계 (od_h1_analysis.py, 2026-08-04 추가)

② 지방 승하차 데이터(2026-01~06)와의 기간 불일치 — 를 해소하기 위해 서울 역간

## analyze.py 연계 제안 (기존 코드 수정은 저자 판단)

1. **승객가중 효율의 가중치 교체** — `analyze.py` 의 운행빈도 가중 대신
   `data/od/processed/node_weights.csv` 의 `boarding_daily_avg + alighting_daily_avg`
   를 노드 가중치로 사용 (수도권 96%+, 전국 90.6% 커버).
2. **단절 통행량 실측** — 역/구간 제거 시 `od_daily_avg.csv` 에서 해당 노드를
   지나는 O-D 쌍의 통행량을 합산하면 "몇 명의 이동이 끊기는가"를 실수요로 정량화.
3. **첨두 취약성** — `od_peak.csv` (주중 07~09시 vs 11~13시)로 시간대별 수요
   편차를 반영한 취약성 비교 가능. README 한계 두 번째 문장("시간대별 수요 편차")
   에 직접 대응.
4. **한계**: OD는 수도권만 실측 (지방은 승하차량만, 역간 OD는 STCIS 신청 필요 —
   `docs/OD_신청_가이드.md`). 7일치(7월 말) 표본이므로 계절 편차는 미반영.
