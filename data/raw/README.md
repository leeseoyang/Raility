# 원본 데이터 배치 안내

이 폴더의 표준데이터는 모두 **국가철도공단**이 공공데이터포털·레일포털을 통해 공개한
파일이며, 로그인 없이 내려받을 수 있다(공공누리 제1유형).

## 저장소에 포함된 파일

```
전체_도시철도역사정보_20260630.xlsx      노드 1,094개 역 (좌표·환승·운영기관)
전체_도시철도노선정보_20260630.xlsx      47개 노선의 정거장 순서
역간거리/                                실측 선로거리 4종 (코레일·서울교통공사·신분당선·대구)
```

## 별도로 내려받아야 하는 파일 (용량 제외)

`전체_도시철도운행정보_20260228.xlsx` (약 18 MB, 223,425행 시각표)는 저장소 용량 때문에
제외되어 있다. `build_graph.py` 실행 전에 아래에서 받아 **이 폴더에 그대로 넣으면** 된다.

- 공공데이터포털: <https://www.data.go.kr/data/15013206/standard.do>
- 레일포털 직접 다운로드: <https://data.kric.go.kr/rips/M_01_01/detail.do?id=900>

이 파일은 구간별 **운행빈도·소요시간 가중치**(OD 데이터 대체) 산출에 쓰인다. 없으면
`build_graph.py`가 실행되지 않는다.
