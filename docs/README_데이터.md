## 2. 데이터 → 그래프 매핑
- **노드(역)** = 역사정보. 전역 고유키 `node_id = 노선번호|역번호`
- **운행엣지(인접)** = 노선정보 `정거장구성`(주) + 운행정보로 끊긴 구간 보완(짧은 다리, <4km)
- **환승엣지** = 동일 역명·좌표근접(<1.2km)·다른 노선
- **엣지 가중치**
  - `거리_m` = 실측 역간거리(있으면) → 없으면 직선거리
  - `거리_실측_m` / `거리_직선_m` (둘 다 보존)
  - `소요시간_s` = 운행정보 구간 소요시간 중앙값
  - `평일운행횟수` = 운행정보 평일 일반열차 편수(**운행빈도 = OD 대체 가중치, 리스크 R1 대응**)

## 4. 데이터 품질 특이사항 & 정제 결정 (분석 전 필독)
1. **역번호는 전역 고유값이 아님**(기관·노선별 로컬코드, 도시 간 충돌) → 복합키 `노선번호|역번호` 사용.
2. **세 파일의 노선번호·노선명 불일치**(예: 분당선 `I28K1`↔`I4105`) → 노선번호 조인 불가, **역명+좌표 연속성** 매칭.
3. **`정거장구성` 구분자 혼재**(`,`/`+`) 및 **코드 2단 구조**(`211-1-용답`) → 한글 이름만 추출하는 파서.
4. **운행정보 2형식 혼재**: (a) 1행=1정차(시각 有), (b) 1행=열차 전체경로(`+`나열). 둘 다 파싱. **급행·직통 제외**(역 건너뜀 → 인접 왜곡 방지).
5. **역명 개명/오타 보정(별칭)**: 성당못→서부정류장, 신길온천→능길, 성서공단→성서산업단지, 디엠시→디지털미디어시티, 송도달비→송도달빛(오타), 민주묘지→4.19민주묘지, 교대앞→교대.
6. **좌표 오류 3건 보정**(실측거리로 교차검증): 양원역(경의중앙, 원본이 봉화 영동선 양원역 좌표), 마곡(5호선, 발산 좌표 중복), 이촌(4호선, 신용산 좌표 중복).
7. **실측거리 오배열 방지 필터**: 실측/직선 0.4~3.0배 벗어나면 기각(9건), 직선<80m면 실측 신뢰.
