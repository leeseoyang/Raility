## 2. STCIS 교통카드 빅데이터 통합정보시스템 — 지방 도시권 역간 OD의 유일한 경로 (우선순위 2)

| 항목 | 내용 |
|---|---|
| URL | https://www.stcis.go.kr (메인: https://www.stcis.go.kr/wps/main.do ) |
| 운영기관 [확인] | 한국교통안전공단 (국토교통부 산하), 문의 stcis@kotsa.or.kr |
| 제공 내용 [확인 — 메인페이지] | 교통카드 기반 수단별·목적별·환승 통행량, 정류장(역)별 이용량, OD 통행량·통행시간·통행거리, 노선별 혼잡도 등. **전국 단위**(대전·부산·대구 도시철도 포함 기대) |
| 지하철 역간 OD 제공 여부 | OD 지표 제공은 확인됨. **역(정류장) 단위 원시/집계 OD의 다운로드 범위·해상도는 로그인 후 확인 필요 [추정]** |
| 형식 | 웹 조회 + 통계 다운로드, Open API 인증키 발급 메뉴 존재 [확인] |
| 승인 소요기간 | 페이지에 명시 없음 [확인]. 통계 조회는 즉시, 상세 데이터 신청은 내부 승인 절차가 있을 수 있음 [추정 — 가입 후 확인] |

**신청 절차 (조윤상 직접 수행)**
1. https://www.stcis.go.kr 회원가입 (개인 실명 인증 필요할 수 있음)
2. 로그인 → "지역별 대중교통 이용분석" / "주제별 분석" 메뉴에서 **대전·부산·대구 도시철도 역간 OD 조회 가능 여부 확인** (권역·수단 필터에 도시철도가 있는지)
3. 조회 화면에서 다운로드(엑셀/CSV) 지원 시 즉시 저장 → `data/od/`에 `stcis_<도시>_<기간>.csv`로 저장
4. 다운로드 제한(집계 수준·기간 제한)이 있으면 Open API 인증키 발급 신청 또는 stcis@kotsa.or.kr로 데이터 제공 문의
5. 확인 결과(가능/불가, 해상도, 기간)를 `OD_데이터_조사.md`에 추가 기록

**활용목적 예시 문구 (가입/신청 양식용)**
> 학부생 학술연구(도시철도 네트워크 취약성 분석). 국가철도공단 공공데이터 활용 공모전 및 KCI 학술지 투고 목적으로, 대전·부산·대구 도시철도의 역간 기종점 통행량을 이용해 역사 운영중단 시나리오의 승객 영향(단절 통행량, 우회 통행시간 증가)을 정량 분석. 비영리·비공개 원시자료 재배포 없음.

## 3. KTDB 국가교통데이터베이스 — 보조용 (우선순위 3)

| 항목 | 내용 |
|---|---|
| URL | https://www.ktdb.go.kr (자료신청방법: https://www.ktdb.go.kr/www/contents.do?key=203 ) |
| 절차 [확인] | 회원가입 → 신청 자료 선택 → 자료 신청서 작성(소속기관·소속 분류·사용 목적 기입) → (만족도 조사) → 자료 다운로드 |
| 비용 [확인] | 무상 (국가통합교통체계효율화법 제17조의3) |
| 대상 제한 [확인] | 없음 — 학계·일반이용자 포함 |
| 제공 자료 [확인] | 여객 O/D 포함 |
| **핵심 한계 [추정]** | KTDB 여객 OD는 **행정구역/교통존(zone) 단위** 지역 간 통행량으로, 지하철 **역 단위 OD가 아님**. 역 제거 시뮬레이션에 직접 사용 불가. 용도: 논문 서론·배경의 수요 규모 서술, 수도권-지방 통행 패턴 검증 |

**활용목적 예시 문구 (신청서 기입용)**
> [소속] ○○대학교 ○○학과 (학부생) / [분류] 학계 / [사용 목적] 도시철도 네트워크 취약성 분석 학술연구(학술지 투고 및 국가철도공단 공공데이터 활용 공모전 응모)에서 광역권 대중교통 수요의 배경 통계로 여객 기종점통행량(수도권·대전권)을 참고하고자 함. 비영리 연구 목적이며 원자료를 재배포하지 않음.

## 4. 대안: 서울시 빅데이터캠퍼스 (필요 시)

서울시 빅데이터캠퍼스( https://bigdata.seoul.go.kr )는 교통카드 원시 수준 데이터 등 비공개 대용량 데이터를 **방문 분석(캠퍼스 내 분석 환경) 또는 신청 심사** 방식으로 제공한다 [추정 — 일반적 운영 방식, 세부는 사이트에서 확인 필요]. 수도권 역간 OD는 이미 공개 데이터로 확보했으므로 우선순위는 낮다. 다만 ① 서울시 지하철 역별 OD 이메일 요청이 거절되거나 ② 시간대·권종 결합의 더 정밀한 원시 데이터가 필요할 때 대안으로 검토. 신청 시 위 2장의 활용목적 문구를 재사용하면 된다.
