## A. 최우선 — 국내 가장 가까운 선행연구

### A1. 김지우·이건학 (2022) — **무료 PDF 있음. 이것부터 읽으면 됨** [확인]

- **국문** 지하철 시설 구조를 고려한 서울시 지하철 네트워크의 취약성 평가
- **영문** Measuring Network Vulnerability of Seoul Subway Network Considering the Structure of Subway Facilities
- 저자: 김지우(서울대 지리학과 박사과정), 이건학(서울대 지리학과 교수)
- 대한지리학회지 57(4), 2022, 411–424
- DOI: <https://doi.org/10.22776/kgs.2022.57.4.411>
- **PDF(무료 공개)**: <https://www.apub.kr/ebook/geo/057-04-08/06.pdf>
- KCI: <https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002875996>

**내용 요약(초록 기준)** 서울 지하철을 대상으로, **건넘선(crossover)과 환승역 등 지하철 고유 시설 구조**를 반영하고 **시간대별 통행 수요**를 결합해 역·구간 취약성을 평가했다. 오전 첨두에는 주거지 역, 오후 첨두에는 업무지구 역의 취약성이 높게 나타났고, 환승역은 연쇄 위험 때문에 항상 높았다. **2·3·5·9호선의 건넘선 부재 구간**이 가장 취약한 것으로 나왔다.

**우리 연구와의 관계 — 반드시 2장에서 정리할 것**

겹치는 부분: 역·구간 단위 취약성 평가, 수요 결합, 서울 대상.

**차별점 3가지**
1. **공간 범위** — 이 논문은 서울 단독. 우리는 전국 6개 권역을 동일 방법론으로 구축해 **권역 간 위상 격차(순환밀도 0.284~0.000)** 를 비교한다. 다권역 비교는 여기에 없다.
2. **수요 지표의 타당성 자체를 검증** — 이 논문은 시간대별 수요를 *사용*하지만, 그 수요 지표가 타당한지는 검증 대상이 아니다. 우리는 공급 프록시·기관통계·교통카드 3종을 삼각검증해 **프록시 관행 자체를 반증**한다.
3. **표적 공격 전략 비교** — 이 논문에는 순차 제거 시뮬레이션(무작위 vs 정적 vs 적응형)이 없다. 우리의 "정적 표적이 무작위보다 덜 파괴적" 결과는 여기서 다루지 않은 영역이다.

**⚠ 주의 — 우리 계획 하나를 접어야 한다**
구성안의 '선택 작업 5(시간대별 첨두/비첨두 취약성 비교)'는 이 논문이 서울에 대해 이미 수행했다. 그대로 하면 재현에 그친다. 굳이 한다면 **지방 권역(부산·대구·대전)으로 확장**해서 "서울 결과가 지방에도 성립하는가"를 묻는 형태여야 의미가 있다.

**또 하나 얻을 것** — 건넘선(crossover) 개념. 우리 그래프에는 건넘선이 없어서 "역 하나 고장 시 열차 회차 가능 여부"를 반영하지 못한다. 이걸 한계로 명시하고 이 논문을 인용하면 심사에서 성실해 보인다.

## D. 아직 확인 못 한 것 — 직접 검색 필요

**"전국 단위 다권역 비교 선행연구 부재"는 아직 확정하지 못했다.** 웹 검색만으로는 DBpia·RISS 전문이 안 열려서, 없다고 단정하면 위험하다. 초록·서론에 "국내 최초"라고 쓰기 전에 아래를 직접 검색해 확인해주세요.

**DBpia / RISS / KCI 검색어 조합**
- `도시철도 네트워크 취약성`
- `지하철 네트워크 복원력` / `지하철 네트워크 강건성`
- `도시철도 + 전국` / `광역시 지하철 비교`
- `metro network vulnerability Korea`
- `국가철도공단 + 네트워크 분석`

**확인 요령** — 결과 중 (a) 서울 외 도시를 다룬 것, (b) 두 개 이상 도시를 한 연구에서 비교한 것이 있는지만 보면 된다. 있으면 알려주세요. 2장 서술과 기여 주장을 그에 맞게 조정하겠습니다.
